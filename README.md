This repository contains Swift and SwiftUI code for the DrinkIt app, which was developed by my partner, Udi Dolinski, and me. The app enables users to input the drinks they have at home and provides a list of cocktails they can make with those drinks, along with detailed recipes for each.
[Link to download the app in the appstore](https://apps.apple.com/il/app/drinkit-cocktails/id1556027609)

# DrinkIt - Cocktails

DrinkIt is an iOS application designed for cocktail enthusiasts. It allows users to create cocktails with the drinks they already have at home. With a simple interface, users can quickly discover which cocktails they can prepare based on their current inventory.

## Key Features

### Add Drinks

- Find drinks by browsing categories or using a comprehensive list.
- View detailed information about each drink.
- Add drinks to the liquor cabinet to keep track of available ingredients.

### Discover Cocktails

- Identify cocktails that can be made with the drinks in the liquor cabinet.
- Explore all listed cocktails and determine the additional ingredients required to complete recipes.
- Access detailed cocktail recipes and related information.

### Favorites

- Save preferred cocktails for quick and easy access.

### Appearance

- Customize the app's look with light or dark mode to suit individual preferences.
